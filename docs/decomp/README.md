# Decompilation notes

Inherited from [PrimeDecomp](https://github.com/PrimeDecomp/prime): how the
matching decompilation under `src/` and `include/` is worked on. None of it is
needed to build, run or package the port; see `docs/NATIVE_PORT.md` for that.

- `metaforce.md`: converting Metaforce code into matching C++98.
- `map.md`: using the demo build's debug link map.
- `nes-emulator.md`: the NES emulator REL modules.
